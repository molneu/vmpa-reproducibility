# Supplementary Figure 9

Supplementary Figure 9 uses the temsirolimus RNA-seq and western-blot datasets from Figure 6.

See first `reproducibility/figure6/scripts/generate_temsirolimus_vmpa_scores.R` to generate scores.

Next, `scripts/run_supplementary_figure9.R` generates the VMPA score files and then runs the western-blot correlation and plotting scripts stored under `reproducibility/figure6/scripts/wb_correlation`.
